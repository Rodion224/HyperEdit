# HyperEdit

Быстрый и лёгкий текстовый редактор для кода и заметок с современным тёмным интерфейсом в стиле VS Code Dark Modern и движком на базе **CodeMirror 6**.

Создавался как компромисс между перегруженным VS Code (который долго запускается и съедает гигабайты памяти) и Notepad++ (у которого устаревший интерфейс Win32).

---

## Особенности и возможности

* **Высокая скорость работы**: Моментальный отклик при вводе текста, 60/120 FPS прокрутка без подвисаний даже на слабых ПК.
* **Инерционный плавный скроллинг**: Мягкая физическая прокрутка колесом мыши во всех окнах, плавное скольжение курсора (Smooth Caret) и анимированное сворачивание функций на 90°.
* **Встроенный раннер кода и Терминал**:
  * Запуск и остановка скриптов (Python, Node.js, Lua, Bat и др.) с выводом в консоль.
  * Встроенная сессия PowerShell / терминала прямо в нижней панели (`Ctrl + ~`).
* **Вкладки с независимой историей**:
  * Мгновенное переключение вкладок без сброса курсора и положения скролла.
  * Независимая история Undo / Redo для каждого открытого файла.
  * Перетаскивание вкладок (Drag & Drop), дублирование и восстановление закрытых (`Ctrl + Shift + T`).
* **Интеграция с Windows**:
  * Включение пункта «Открыть с помощью HyperEdit» в контекстное меню Проводника прямо из настроек.
  * Автоматическая блокировка случайного открытия "тяжёлых" бинарных файлов (.exe, .dll, .iso и др.).
* **Инструменты разработчика**:
  * Дерево файлов рабочей папки (Workspace Explorer) с созданием/удалением/переименованием.
  * Палитра команд (`Ctrl + Shift + P`) и быстрое открытие файлов (`Ctrl + P`).
  * Интерактивный Color Picker (всплывающая палитра цветов для HEX/RGB).
  * Подсветка синтаксиса для 20+ языков и автодополнение.
* **Полная мультиязычность**: Интерфейс переведён на русский, английский и другие языки.

## Запуск и сборка

Приложение полностью автономно и работает **без интернета**.

### Быстрый запуск
* Дважды кликните по файлу `launch.bat` (Windows).

### Запуск через консоль разработчика
```bash
# Установка зависимостей (при первом клонировании)
npm install

# Запуск в режиме разработки
npm start
```

### Сборка релизной версии
```bash
npm run build
```

## Основные горячие клавиши

| Сочетание | Действие |
| :--- | :--- |
| `Ctrl + N` | Создать новый файл |
| `Ctrl + O` | Открыть файл с диска |
| `Ctrl + S` | Сохранить текущий файл |
| `Ctrl + W` | Закрыть вкладку (также клик средней кнопкой мыши) |
| `Ctrl + Shift + T` | Восстановить последнюю закрытую вкладку |
| `Ctrl + B` | Скрыть / показать боковую панель |
| `Ctrl + Shift + P` | Палитра команд (Command Palette) |
| `Ctrl + P` | Быстрый поиск файлов (Quick Open) |
| `Ctrl + F` | Поиск и замена с поддержкой RegEx |
| `Ctrl + G` | Плавный переход к номеру строки |
| `Ctrl + ,` | Открыть настройки редактора |
| `Ctrl + ~` | Открыть/скрыть нижнюю панель терминала |

## На VirusTotal могут быть срабатывания. Почему?
**Антивирусы любят срабатываться когда у файла отсутсвует платная подпись, когда не могут найти известные сигнатуры файла. Если вы не доверяете можете проанализировать исходный код или же используйте программу на виртуальной машине.**
